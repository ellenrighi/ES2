#  Engenharia de Software II - Xadrez

Este projeto foi desenvolvido utilizando a biblioteca **PPlay**.

---

##  Pré-requisitos

Antes de começar, certifique-se de ter instalado em seu computador:

1. **Python 3.8+** (recomendado Python 3.8 ou superior)

2. **Pygame** (dependência gráfica utilizada pelo PPlay)
   - pip install pygame

---

## Como Rodar o Jogo

### 1. Clonar ou Baixar o Repositório
Abra o terminal (Prompt de Comando, PowerShell ou Terminal do Linux/macOS) na pasta do projeto.

### 2. (Opcional, mas Recomendado) Criar e Ativar um Ambiente Virtual
Para evitar conflitos de dependências no seu sistema:

**No Windows:**
```bash
# Criar o ambiente virtual
python -m venv .venv

# Ativar o ambiente virtual
